# Karan Gupta — Game Developer Portfolio

A standalone, static portfolio for game and XR development. Its required project images and videos are included in `assets/`.

## Run locally

From this directory, start a local web server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000/](http://localhost:8000/) in a browser. Stop the server with `Ctrl+C`.

The site has no build step or npm dependencies. Opening `index.html` directly may prevent some browsers from loading media reliably, so use the local server.
